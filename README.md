# pass-strength
To check the password is weak, medium or strong.

🔑 Password Strength Checker

A Python project that analyzes the strength of passwords using two different methods:
Manual Character-Based Analysis – Checks password strength by evaluating lowercase, uppercase, digits, punctuation, spaces, and length.
Library-Based Analysis with zxcvbn – Uses the advanced zxcvbn library (developed by Dropbox) to provide realistic password strength scoring.
This project is version-controlled with Git and hosted on GitHub for collaboration and sharing.

🚀 Features

Secure password input using getpass (no password shown on screen)
Custom password strength evaluator built from scratch
Integration of the zxcvbn library for advanced password analysis
Strength categories: Very Weak → Very Strong
Beginner-friendly Python code for learning string manipulation, conditions, and libraries
Git/GitHub workflow for project hosting and version control

🧰 Tech Stack

Python 3
string (built-in Python module)
zxcvbn (external library for password strength estimation)
Git & GitHub for version control and collaboration

🌟 Key Learnings

Handling secure password input with getpass
String manipulation & conditional logic in Python
Leveraging external libraries for smarter solutions
Using Git & GitHub for version control and project hosting
